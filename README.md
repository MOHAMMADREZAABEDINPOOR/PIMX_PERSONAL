## ⚡ Features
- ☁️ **Multi-Cloud Ready**: Preconfigured manifests for Vercel (`vercel.json`), Render (`render.yaml`), and Cloudflare (`wrangler.toml`).
- 🎨 **Dynamic Bento-Grid UI**: Modern bento layout showcasing projects, tech stack metrics, and interactive resume modules.
- ⚡ **Zero Latency**: Asset preloading, optimized bundling, and client-side page routing.
